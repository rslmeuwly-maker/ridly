Explorer les reels RIDLY

Découvre toutes les vidéos verticales postées sur RIDLY. Tape un pseudo, un hashtag ou un mot-clé, puis tape sur une tuile pour ouvrir le reel. Swipe de bas en haut / haut en bas pour changer de vidéo.

Chargement des reels…

Astuce : les reels sont créés via la page Ajouter en mode Reel (Recherche). Les catégories sont ajoutées entre crochets dans la légende (ex: [Street]).
Tu peux aussi mettre une note de 1 à 5 roues sur chaque reel dans le viewer.
